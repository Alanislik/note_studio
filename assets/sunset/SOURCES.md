# Источники медиа

- `sunset.jpg` — найденный фан-арт заката Deltarune из публичного репозитория [nerdynerdenson-spec/deltarune-sunset](https://github.com/nerdynerdenson-spec/deltarune-sunset), коммит `402dc2e092cadeba621ea890c65a6ff1c62dfc04`. Автор исходного рисунка в репозитории не указан. Это фан-арт, а не кадр игры.
- `kris.png`, `susie.png`, `ralsei.png` — исходные PNG из [ThePlasticPotato/Featherfall](https://github.com/ThePlasticPotato/Featherfall), коммит `4c4df5fb842b6e23936249aca5d5bfcd385f8073`. Проект описан авторами как порт платформенной механики Deltarune Chapter 5 в Kristal. Использованы кадры прыжка персонажей; изображений боя с Титаном здесь нет.

Изображения сохранены без изменения исходных байтов. Точные ссылки на каждый файл и SHA-256 записаны в `sources.json`. Кадрирование и движение выполняются элементами `<img>` в приложении. Сцена является монтажом по референсу пользователя, а не восстановленной кат-сценой.
