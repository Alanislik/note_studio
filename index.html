Эффекты нот

Настройки сохраняются отдельно для каждого произведения.

Звучащие ноты подсвечиваются выбранным цветом. Показан один такт: по его окончании строка сменится автоматически. При паузе подсветка сохраняется; остановка возвращает к первому такту. Для точного импорта рекомендуются файлы MusicXML (.musicxml, .xml, .mxl) или MIDI (.mid, .midi).
