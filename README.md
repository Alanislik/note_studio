# Nota Studio — музыкальная библиотека с нотами

Веб-приложение на HTML, CSS и JavaScript с локальным сервером Python 3 для хранения файлов. Внешние Python-пакеты не нужны.

## Возможности

- Поиск музыки по названию, композитору и жанру; фильтры и сортировка.
- Загрузка MusicXML (`.musicxml`, `.xml`), сжатого MusicXML (`.mxl`) и MIDI (`.mid`, `.midi`).
- Отображение одного такта на одной строке с помощью OpenSheetMusicDisplay; при завершении такта появляется следующий.
- Фиолетовая подсветка звучащих нот, включая аккорды и удерживаемые звуки, и подписи нот (например, C4, E4). Все инструменты / обе руки фортепиано показываются вместе.
- Воспроизведение через Web Audio с мягким синтезированным фортепианным тембром, управление паузой, остановкой, перемоткой и темпом.
- Оригиналы нот и вложения в отдельной папке `data`, библиотека, избранное и настройки в SQLite без регистрации.
- Раздел «Мои файлы» со скачиванием оригиналов.
- Несколько аудио, видео и изображений под партитурой; привязка к времени плеера.
- Цвет, свечение и пульсация звучащих нот с сохранением для каждого произведения.
- Пять демонстрационных произведений, адаптивный дизайн.

## Запуск

Распакуйте архив, откройте терминал в папке проекта и выполните:

```bash
python3 server.py
```

Откройте http://localhost:8000

Для первого запуска нужен интернет: библиотеки нот, MIDI, MXL и шрифты загружаются с CDN. Сервер по умолчанию доступен только на этом компьютере. SQLite и файлы создаются автоматически в папке `data` рядом с `server.py`. Установка базы данных не нужна. Если используется старый статический HTTP-сервер, библиотека продолжит работать в браузере, но для загрузки медиа и хранения в `data` нужен `server.py`.

## Где лежат файлы

```text
data/
  library.sqlite3          # библиотека, избранное, эффекты и таймкоды медиа
  uploads/<id произведения>/<id файла>.<расширение>
```

Оригиналы MusicXML/MXL/MIDI сохраняются без изменения байтов. Имена и связи с произведениями находятся в базе; в интерфейсе видны исходные имена и кнопки скачивания. Файлы не отправляются во внешнее облако. `data` указана в `.gitignore`; в текущем репозитории ранее добавленная библиотека уже отслеживается Git. Архив обновления кода не включает её. При обновлении приложения сохраните эту папку.

Можно выбрать другую папку: `python3 server.py --data-dir /путь/к/моим-нотам`. Другой порт: `python3 server.py --port 8001`. Все пользователи одного запущенного сервера используют его общую библиотеку; регистрации и разделения по аккаунтам пока нет.

Старая библиотека браузера остаётся нетронутой. Откройте сайт по прежнему адресу (тот же хост и порт), зайдите в «Мои файлы» и нажмите «Перенести библиотеку из браузера». Для старых MusicXML сохраняется доступная копия партитуры, для старых MIDI — сохранённые MIDI-данные; исходное имя старой загрузки может быть неизвестно. Произведения с уже существующим ID не перезаписываются. В случае ошибки повторите перенос.

## Медиа под нотами и эффекты

Откройте произведение и используйте «Добавить файлы» под нотным блоком (над плеером). Там же остаётся список всех вложений с настройками; вне своего отрезка привязанная карточка приглушается. В самом блоке с нотами медиа появляется под партитурой только на своём отрезке («С»…«До») и пропадает, когда время вышло; вложения без флажка «С плеером» под нотами не показываются. Можно выбрать сразу несколько файлов: PNG/JPEG/WebP/GIF, MP3/WAV/OGG/FLAC/M4A, MP4/WebM/MOV, до 100 МБ каждый. Фактическая поддержка кодеков зависит от браузера. У каждого аудио и видео есть отдельный регулятор громкости от 0 до 100%, который действует сразу и сохраняется для этого вложения. У каждого вложения есть скачивание и удаление; удаление произведения удаляет его файлы и вложения.

Без флажка «С плеером» аудио и видео воспроизводятся собственными кнопками. С флажком задайте «С» и, при необходимости, «До» в секундах партитуры. «Начать отсюда» подставляет текущую позицию нот. Пустое «До» означает до конца произведения. На выбранном участке карточка выделяется, вне его приглушается. Аудио и видео следуют пуску, паузе, перемотке и темпу нот; изображения выделяются на своём участке. Медиа запускается с собственного начала в момент «С». На телефонах браузер может попросить сначала нажать кнопку воспроизведения самого медиа. Это локальные вложения, ссылки на YouTube и другие сайты пока не поддерживаются.

Над медиа находятся настройки цвета, свечения и пульсации звучащих нот. Они сохраняются для каждого произведения и применяются при следующем открытии. При системной настройке уменьшения движения пульсация отключается.

## Размеры изображений и видео

В карточке вложения раздел «Размер под нотами» задаёт ширину сцены (20–100%), высоту (80–720 px) и кадрирование. «Вписать целиком» сохраняет изображение полностью и его пропорции; «Заполнить с обрезкой» заполняет заданный прямоугольник без растяжения. Ползунки дают предварительный просмотр сразу, изменение сохраняется после отпускания. «Сбросить размер» возвращает 100% × 320 px. Размеры действуют и на видео, перенесённое из карточки в сцену; звук продолжает играть при настройке. Миниатюры в карточках ограничены по высоте для удобства редактирования. Старые вложения получают размер по умолчанию, миграция базы не требуется.

## Авторский визуал Sunset of Seven Suns

Для произведений с названием или исходным именем `Sunset of Seven Suns.mid` автоматически включается сцена «Семь солнц» прямо под нотным станом. Это нарисованный в Canvas пейзаж: семь цветных солнц, горные силуэты, отражения на воде и светящиеся частицы. Ноты мелодии управляют свечением солнц, нижняя партия — движением отражений. Сцена использует ту же шкалу времени, что звук и подсветка нот: пауза замораживает кадр, перемотка восстанавливает его, изменение темпа сохраняет связь с плеером. Дополнительные изображения, видео и внешние библиотеки для визуала не нужны.

Щелчок по пейзажу перематывает ноты. Ползунок под пейзажем показывает кадр при перетаскивании и перематывает звук после отпускания. В «Эффектах нот» можно включать сцену и для других произведений, выключать её и менять отклик на ноты. Настройки сохраняются отдельно для каждого произведения. Системное уменьшение движения отключает вспышки и движение частиц.

Анализ библиотеки из коммита `ab3ebbf`: оригинальный MIDI Sunset содержит 1007 нот в двух фортепианных партиях и длится около 96 секунд. Сохранённая в этой версии конвертация MusicXML содержит четыре переполненных такта и проигрывается за 97,125 секунды. Визуал следует фактической шкале этой партитуры. Исходные MIDI и существующая библиотека сохраняются; исправление старой конвертации — отдельное изменение.

## Ограничения

- MP3/WAV — это аудио, из него нельзя автоматически получить точные ноты без отдельной системы транскрипции. Для получения нот поддерживаются **MIDI и MusicXML**. MP3/WAV можно прикрепить к произведению как аудиозапись.
- MIDI конвертируется в MusicXML упрощённо: квантование до шестнадцатых, без сохранения сложных лиг, динамики, нескольких голосов и некоторых особенностей партитуры. Для синхронизации звук воспроизводится по полученным нотам, то есть после квантования, а не по исходному MIDI. Используется стартовый темп MIDI; его последующие изменения при конвертации не сохраняются.
- Для сложных MusicXML проигрыватель также упрощён: повторы и переходы не исполняются (движение по тактам один раз подряд), транспонирование и отдельные тембры инструментов не учитываются. Численные изменения темпа в первой партии и связанные ноты учитываются; плавные ускорения/замедления и форшлаги не воспроизводятся.
- Приложение локальное, не ищет музыку во внешнем интернете. Поиск работает среди добавленных и демонстрационных произведений. Для общественного каталога нужны сервер, пользователи, хранилище файлов, лицензии на публикацию музыки и поисковый индекс.
- Старые данные IndexedDB могут исчезнуть при очистке браузера. Новые файлы в `data` от очистки браузера не зависят. Резервируйте всю папку `data`, включая SQLite.

## Прослушивание по тактам

1. Загрузите MusicXML/MXL или MIDI либо откройте пример.
2. Нажмите ▶: звучащие ноты станут фиолетовыми. Длительные ноты остаются подсвеченными до окончания их длительности. Паузы не подсвечиваются.
3. По окончании такта его строка автоматически заменится следующей; многоголосная партитура показывает все нотные станы текущего такта вместе.
4. Пауза сохраняет позицию и подсветку. Повторное ▶ продолжает с этой позиции; ■ возвращает к первому такту.
5. Щелчок по полосе времени перематывает звук и ноты одновременно. При воспроизведении музыка продолжается автоматически.
6. Изменение темпа применяется к текущей позиции, увеличение/уменьшение и изменение ширины окна сохраняют текущий такт.

Ноты подсвечиваются по общей временной шкале плеера. Звук заранее планируется на аудиочасах Web Audio: перерисовка страницы и задержки JavaScript не сдвигают отдельные ноты. У каждой ноты независимый голос, плавная атака и затухание; при продолжении удерживаемая нота возобновляется с учётом её затухания. Тембр синтезируется локально и не требует Tone.js или загрузки аудиосэмплов. Это синтез фортепиано, а не запись акустического инструмента. Нотные строки разделены по тактам только для показа; исходный загруженный файл не меняется.

## Проверка обновления

Проверены расчёты аккордов, длительных нот и лиг, пауз, смены численного темпа, перемотки, остановки и восстановления подсветки после перерисовки. Также проверена связь SVG-нот и строк с реальным OpenSheetMusicDisplay 1.9.0 в DOM-окружении Node.js. После замены звукового движка дополнительно проверены в Chromium: открытие SVG-партитуры, подсветка, пауза/продолжение, перемотка, смена темпа, остановка и уход из плеера. Проверка включала искусственную блокировку главного потока на 700 мс. Автотесты OfflineAudioContext проверяют реальный аудиосигнал, аккорды и повторяющиеся ноты, отмену будущих звуков, продолжение и масштабирование темпа. Прослушивание человеком в среде подготовки не выполнялось.

Запуск аудиотестов: `node --test tests/audio-engine.cjs`. Нужны Node.js, пакет `playwright` и Chromium (по умолчанию `/usr/bin/chromium`; другой путь задаётся переменной `CHROMIUM_PATH`). Сетевые библиотеки и работающий сервер для этих тестов не требуются.

## Структура

- `index.html` — разметка интерфейса
- `styles.css` — оформление
- `app.js` — библиотека, разбор MusicXML и MIDI, партитура, плеер и поиск (файл разбит на пронумерованные разделы с комментариями)
- `audio-engine.js` — локальный синтез тембра и точное планирование звука
- `tests/audio-engine.cjs` — регрессионные тесты аудиосигнала
- `server.py` — API хранения и сервер сайта
- `sunset-visual.js` — рисование и интерактивность сцены «Семь солнц»
- `studio.js` — файлы, вложения, синхронизация и эффекты
- `tests/studio.cjs`, `tests/test_server.py` — проверки студии и хранения

## Следующий этап

Чтобы превратить прототип в онлайн-платформу: FastAPI/Django или Node.js backend, PostgreSQL, S3-совместимое файловое хранилище, регистрация пользователей, полнотекстовый поиск по общему каталогу, авторские права и админ-панель. 60 страниц не нужны: достаточно нескольких основных экранов, которые динамически показывают любое количество произведений.

## Проверки хранения и студии

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/audio-engine.cjs tests/studio.cjs tests/sunset.cjs
```

Для браузерных тестов нужны Playwright и Chromium, для теста студии также `curl` и доступ к CDN OpenSheetMusicDisplay. Проверка TLS включена; загруженная библиотека подставляется в браузер, чтобы использовать системное доверие прокси, остальные внешние запросы отключены. Уже загруженный файл можно передать через `OSMD_TEST_SCRIPT=/путь/к/opensheetmusicdisplay.min.js`. Тесты запускают собственный сервер с временной папкой `data`, не затрагивая вашу библиотеку.

`tests/sunset.cjs` проверяет реальную сохранённую партитуру Sunset на временной копии `data`: реакцию на ноты, паузу, перемотку, мобильный экран и сохранение настроек. Исходная библиотека не изменяется.
